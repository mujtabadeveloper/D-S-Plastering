# D S Plastering Website

Responsive static website with unique imagery, animations, photo lightbox and WhatsApp enquiry form.

## GitHub
Extract the ZIP and upload its contents to your repository root. No install or build step is needed.

## Vercel
Import the GitHub repository. Select Framework Preset: Other. Leave Build Command empty and use the repository root as Output Directory.

## Local preview
Run `python -m http.server 8000`, then open http://localhost:8000.

## Editing
- index.html: copy, sections and business contact details
- style.css: colors, spacing, responsive layout and animation
- app.js: mobile menu, gallery lightbox and WhatsApp enquiry
- assets/: logo and all photographs

The enquiry form prepares a WhatsApp message for the visitor to send. Google Fonts requires an internet connection and has local font fallbacks. Service imagery includes AI-generated illustrative photos; project photos are sourced from the business website.
